🤖 TechMart AI: Akıllı Müşteri Deneyimi Platformu
YZTA 5.0 Hackathon kapsamında geliştirilen TechMart AI, KOBİ'lerin müşteri iletişim süreçlerini yapay zeka ile dijitalleştiren, sadece konuşan değil aynı zamanda aksiyon alan bir asistan çözümüdür.

🌟 Öne Çıkan Özellikler
Gemini 2.0 Flash Entegrasyonu: En güncel üretken AI modeli ile doğal ve hızlı sohbet deneyimi.

Tool Calling (Ajan Yapısı): Asistanın sadece bilgi vermesini değil; stok sorgulama, sipariş takibi ve iade işlemleri yapmasını sağlayan otonom yapı.

Modern Backend: FastAPI ile asenkron, yüksek performanslı ve ölçeklenebilir mimari.

Kullanıcı Dostu UI: Müşterileri yönlendiren "Akıllı Taslak" butonları ve duyarlı (responsive) tasarım.

🛠️ Teknik Mimari
Dil: Python 3.10+

Web Framework: FastAPI

AI Model: Google Gemini 2.0 Flash (Agent & Tool Calling)

Frontend: HTML5, CSS3, JavaScript (Vanilla)

Ortam Yönetimi: Dotenv (.env)

🚀 Kurulum
Depoyu klonlayın:

Bash
git clone https://github.com/KULLANICI_ADIN/techmart-ai.git
cd techmart-ai
Gerekli kütüphaneleri yükleyin:

Bash
   pip install -r requirements.txt
.env dosyasını oluşturun ve API anahtarınızı ekleyin:

Kod snippet'i
   GEMINI_API_KEY=KENDI_API_ANAHTARINIZ
Uygulamayı başlatın:

Bash
   python main.py
Uygulama http://localhost:8001 adresinde çalışmaya başlayacaktır.
